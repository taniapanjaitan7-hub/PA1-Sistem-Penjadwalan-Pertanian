# 🌱 Sistem Penjadwalan Pertanian — PA 1

Sistem Penjadwalan Pertanian merupakan proyek akademik kelompok pada **Proyek Akhir Tahun 1 (PA 1)** di Institut Teknologi Del.

Aplikasi ini dirancang sebagai platform digital untuk membantu petani dalam merencanakan, mencatat, dan memantau kegiatan pertanian secara lebih terstruktur dan efisien.

## 🎯 Tujuan

Menyediakan platform digital bagi petani untuk mengelola jadwal kegiatan pertanian sehingga proses perencanaan, pencatatan, dan pemantauan dapat dilakukan dengan lebih mudah dan terorganisir.

## ✨ Fitur Utama

- Dashboard
- About Us
- KRT (Kelompok Rencana Tanam)
- Pengeluaran Tanaman
- Laporan Panen
- Tutorial Perawatan
- Monitoring Pendapatan
- Pengelolaan Alat & Bahan
- Tambah Lahan
- Tambah Tanaman
- Tambah KRT
